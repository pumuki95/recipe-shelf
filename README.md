# The Recipe Shelf

My recipe collection, built from YouTube and Instagram cooking videos.

Live site: https://pumuki95.github.io/recipe-shelf/

Each recipe has a photo of the finished dish, servings, cook time, nutrition, tags, a scalable ingredient list and step-by-step instructions. Recipes added to the grocery list are combined and sorted by aisle.

## How it's organised

- `index.html` – the site
- `recipes.json` – all recipes, generated by `python3 build.py`
- `data/` – one file per video with its recipes (`_playlist-order.txt` sets the order, newest first)
- `img/` – a photo of each finished dish, taken from the video
